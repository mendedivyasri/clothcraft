# Clothing Store

A full-stack starter for a local clothing store.

## Included
- React + Vite frontend
- Node.js + Express backend
- Product catalog
- Admin product management starter
- Customer registration/login starter
- Cart
- 30 km delivery eligibility check
- Order API starter
- SQLite database for easy local development

## Run

### Backend
cd backend
npm install
npm run dev

### Frontend
cd frontend
npm install
npm run dev

Frontend: http://localhost:5173
Backend: http://localhost:5000

## Important
This is a development-ready foundation, not yet a payment-production deployment. Before accepting real payments, add a production payment gateway, HTTPS, secure secrets, stronger validation, proper authentication/session handling, backups, and deploy the backend/database using a production service.
